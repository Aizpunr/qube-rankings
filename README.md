# QotW Rankings

Wins, podiums and best finishes for **QotW (Qube of the Week)** — the Thursday Zeepkist cup hosted by [lillyfenn](https://www.twitch.tv/lillyfenn).

Live page: https://aizpunr.github.io/qube-rankings/

## What it tracks

Cup placements across every QotW cup, counted as **wins**, **podiums** (top 3) and **best finish**. Sorted by wins, then podiums. No ELO.

- **Season 1** (cups #1–~26) totals come from the host's official standings — this includes cups with no per-cup detail (#8, #9, #20–26).
- **Season 2** (#27 on) is counted from full per-cup results.

Player history (click any row in Rankings): per-cup table (cup #, date, map, finishing position) for the cups we have on record.

Events tab: every cup we have, sortable by date / SOF / lobby size, click to see full final standings.

## Data source

Source files (per-cup markdown, build script, xlsx, and `season1_podiums.json` — the host standings) live in the working folder, not this repo. This repo holds the published page + the prebuilt `qube.json` only.
